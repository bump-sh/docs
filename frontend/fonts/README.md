# Fonts

The site uses the same type as the Bump.sh API documentation:

- **Inter** (variable, uprights and italics) for text and headings,
- **JetBrains Mono** (regular and semibold) for code.

Both are licensed under the SIL Open Font License 1.1, see `OFL-Inter.txt` and `OFL-JetBrainsMono.txt`. The files come from the Bump.sh application repository (`app/javascript/fonts`) so both projects stay in sync.
